# SOURCE PACK — SER 14 Trouver un produit à vendre — sourcing & validation

Revue : 29/09/2026 — France / UE.

## Règles de validation à préserver

- Une recherche INPI à l'identique est un premier niveau de vérification, pas une garantie absolue de disponibilité juridique du nom.
- Avant sourcing, identifier la catégorie réglementaire réelle du produit : sécurité générale, CE si applicable, électrique, jouet, cosmétique, alimentaire, EPI, batterie, etc.
- Un certificat fournisseur isolé ne suffit pas à démontrer la conformité d'un produit.
- Si le vendeur devient importateur dans l'UE ou commercialise sous sa propre marque, ses responsabilités peuvent augmenter selon la législation applicable.
- La validation commerciale (demande, marge, retours, acquisition) et la validation réglementaire sont deux contrôles séparés.

## Checklist fournisseur

- [ ] identité légale vérifiable ;
- [ ] adresse et interlocuteur ;
- [ ] échantillon réel ;
- [ ] matériaux / composition / spécifications ;
- [ ] documents de conformité correspondant exactement à la référence testée ;
- [ ] traçabilité lot / modèle ;
- [ ] pays d'expédition et Incoterm si pertinent ;
- [ ] politique défauts / retours / rappel ;
- [ ] capacité à fournir documentation aux autorités si nécessaire.

Pour une catégorie réglementée, créer un mini source pack sectoriel avant validation du produit.
