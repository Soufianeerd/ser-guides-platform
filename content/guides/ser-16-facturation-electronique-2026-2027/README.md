# SER 16 — Facturation électronique 2026–2027

Statut : **prépublication / production éditoriale**

## Positionnement
Guide pratique pour indépendants, micro-entreprises et TPE françaises afin de comprendre la réforme, choisir leur organisation et préparer réception/émission sans jargon.

## Échéances à figer dans le contenu
- 1er septembre 2026 : réception obligatoire pour toutes les entreprises concernées ; émission pour grandes entreprises et ETI.
- 1er septembre 2027 : émission pour PME et micro-entreprises.
