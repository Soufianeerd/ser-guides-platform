# 5 — Construire une annonce qui ressort dans la recherche

Vinted recommande de fournir jusqu'à 20 photos nettes, un titre et une description détaillée, la catégorie appropriée, la marque correcte, l'état réel, le prix et la taille de colis. [S02]

## Le titre

Un bon titre contient les éléments que l'acheteur recherche réellement :
- type d'article ;
- marque ;
- modèle / coupe ;
- taille ;
- couleur ou matière si utile.

Évitez le bourrage de mots-clés ou l'utilisation de marques sans rapport. [S02]

## La description

Répondez aux objections avant qu'elles soient posées :
- état précis ;
- mesures ;
- matière ;
- défauts ;
- contexte utile ;
- contenu inclus ;
- authenticité / preuve quand pertinent.

## Recommandation

Vinted indique que la pertinence de la description, les filtres / requêtes, le type de vendeur et d'autres paramètres peuvent influencer la recommandation des annonces. [S05]

Votre objectif : être **pertinent**, pas manipuler l'algorithme.
