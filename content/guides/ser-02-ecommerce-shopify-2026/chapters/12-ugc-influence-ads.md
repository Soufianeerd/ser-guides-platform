# 12 — UGC, créateurs et publicité

## UGC

Le contenu UGC peut servir à produire :
- démonstrations ;
- témoignages encadrés et authentiques ;
- scénarios d’usage ;
- publicités natives.

Ne demandez jamais un faux témoignage.

## Brief créateur

Votre brief doit contenir :
- cible ;
- problème ;
- bénéfice principal ;
- éléments interdits ;
- preuves disponibles ;
- format ;
- CTA ;
- durée ;
- droits d’utilisation ;
- date de livraison.

## Micro-créateurs

Un créateur de 8 000 abonnés très spécialisé peut générer plus de ventes qu’un compte généraliste de 200 000 abonnés.

Évaluez :
- pertinence audience ;
- qualité commentaires ;
- historique sponsorisé ;
- qualité vidéo ;
- capacité à expliquer ;
- tarif / contenu.

## Paiement

Séparez :
- création du contenu ;
- publication sur son compte ;
- droits publicitaires ;
- exclusivité ;
- durée d’utilisation.

## Publicité : ordre de test

Ne lancez pas 12 audiences et 20 créatifs.

Commencez :
1. 3–5 créatifs différents ;
2. une offre identique ;
3. un tracking propre ;
4. un budget plafond ;
5. une durée suffisante pour lire le signal.

## Diagnostic pub

### CPM élevé
Le marché, l’audience ou la période peut être coûteuse.

### CTR faible
Le créatif ou le message n’attire pas.

### CTR bon, conversion faible
La page, l’offre, le prix ou la confiance posent problème.

### Conversion bonne, rentabilité faible
Le CAC est trop élevé ou votre marge trop faible.

## Règle

La publicité amplifie un système. Elle n’invente pas un bon produit.
