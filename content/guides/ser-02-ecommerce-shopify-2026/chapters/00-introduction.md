# 00 — Introduction

## Ce que vous allez construire

À la fin de ce guide, vous devez être capable de répondre à cinq questions sans hésiter :

1. **Qu’est-ce que je vends ?**
2. **À qui ?**
3. **Pourquoi cette personne achèterait-elle chez moi ?**
4. **Combien me reste-t-il réellement par commande ?**
5. **Comment vais-je obtenir mes premières ventes de façon mesurable ?**

Le marché existe : selon la FEVAD, le e-commerce français a atteint **196,4 milliards d’euros en 2025**, avec 3,2 milliards de transactions. Cela ne signifie pas qu’une boutique créée aujourd’hui trouvera automatiquement des clients. Cela signifie que le commerce en ligne est devenu un canal mature, concurrentiel et installé dans les habitudes. [S1]

## Le piège classique

Beaucoup de débutants commencent dans cet ordre :

logo → thème Shopify → couleurs → applications → produits → contenu → puis seulement : « comment vendre ? »

SER vous propose l’ordre inverse :

**problème → client → offre → marge → preuve → boutique → trafic → mesure → optimisation**

Shopify est un outil. Une boutique n’est pas un business tant que l’offre, l’économie unitaire et l’acquisition ne fonctionnent pas.

## Votre règle de travail

À chaque décision, écrivez :
- ce que vous pensez être vrai ;
- comment vous allez le vérifier ;
- le chiffre qui vous dira si vous avez raison.

Exemple :
> Hypothèse : « les étudiants veulent une gourde compacte qui tient dans un sac ».  
> Test : 5 vidéos organiques + une page simple.  
> Mesure : clics, ajouts panier, ventes.

Vous ne cherchez pas à avoir raison immédiatement. Vous cherchez à **apprendre rapidement sans brûler votre budget**.
