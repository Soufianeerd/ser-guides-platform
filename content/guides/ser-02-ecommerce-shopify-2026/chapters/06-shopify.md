# 06 — Construire Shopify sans perdre une semaine sur le design

Shopify propose un parcours de configuration couvrant notamment produits, boutique, paiements et lancement. [S3][S5][S7]

Votre objectif n’est pas de faire un site « impressionnant ». Votre objectif est de rendre l’achat simple et rassurant.

## Architecture minimale

Navigation recommandée pour une petite boutique :
- Accueil
- Boutique / catégories
- Produit
- À propos
- FAQ
- Contact

Footer :
- livraison
- retours
- CGV
- mentions légales
- confidentialité
- cookies selon configuration

## Home

La home doit rapidement expliquer :
- ce que vous vendez ;
- pour qui ;
- bénéfice ;
- produits phares ;
- preuves ;
- livraison / confiance ;
- CTA.

## Theme

Choisissez d’abord un thème :
- rapide ;
- responsive ;
- lisible ;
- compatible avec les fonctions nécessaires.

N’ajoutez pas une application pour chaque détail visuel.

## Paiements

Shopify Payments est disponible en France métropolitaine, sous réserve d’éligibilité et de vérification des informations demandées. [S6]

Testez :
- paiement carte ;
- paiement mobile lorsque disponible ;
- refus de paiement ;
- remboursement ;
- e-mail de confirmation.

## Livraison

Créez une règle compréhensible :
- zones ;
- prix ;
- seuil gratuit éventuel ;
- délais réalistes ;
- tracking.

La promesse affichée doit correspondre à votre capacité réelle.
