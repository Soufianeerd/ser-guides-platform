# QA ROLLUP — Guides 02 à 15 — 29/09/2026

## Ce qui est produit sur cette branche

- 14 web-books HTML interactifs autonomes (SER 02–15).
- source éditoriale `ebook.md` pour SER 03–15 ; SER 02 conserve aussi sa source existante.
- SOURCE_PACK pour SER 03–15 ; SER 02 conserve son source pack détaillé.
- manifest de production pour chaque guide.
- README synchronisés.
- audit de cohérence de roadmap.

## Contrôles déjà intégrés au rendu HTML

- responsive viewport ;
- navigation étape précédente / suivante ;
- progression visible ;
- reprise locale via localStorage ;
- checklist persistante ;
- noindex/nofollow/noarchive ;
- aucun secret ni accès privé embarqué ;
- aucun prix inventé ;
- aucune promesse de revenu, viralité ou rentabilité garantie.

### P0 — commercial
- décider le prix de chaque guide 02–15 ;
- créer les produits/prix/liens Stripe ;
- mapper chaque produit vers le bon fichier de livraison/entitlement ;
- tester achat → webhook → email/bibliothèque → accès.

### P0 — visuel
- produire les 3 visuels définitifs par guide (hook, valeur, produit) ;
- copier les decks publics sur le site ;
- vérifier cohérence couverture/site/ebook.

### P1 — export
- produire et contrôler les PDF si l’export PDF est conservé comme livrable ;
- vérifier la pagination <= 35 pages.

## Verdict

**Les e-books 02–15 existent désormais comme produits éditoriaux et web-books de prépublication.**
Ils ne sont volontairement pas marqués `READY` ni publiés commercialement tant que les bloqueurs P0 ci-dessus ne sont pas fermés.

Cette distinction évite de mettre en vente un guide dont le contenu existe mais dont le paiement, la livraison, les visuels ou la QA finale ne sont pas encore validés.
