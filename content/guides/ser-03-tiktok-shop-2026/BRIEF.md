# SER Guide 03 — TikTok Shop 2026

Statut : **web-book FR prêt à livrer**

## Objectif

Aider un vendeur basé en France à passer d'une idée de produit à une boutique TikTok Shop réellement exploitable : inscription, conformité, marge, catalogue, contenu, affiliation, LIVE, logistique, retours et pilotage des premières ventes.

## Positionnement

Pas de promesse de revenus rapides. TikTok Shop est traité comme un canal e-commerce à part entière : il faut un produit autorisé, une marge suffisante, une logistique fiable et un système de contenu mesurable.

Le guide distingue toujours :
- les règles officielles TikTok Shop ;
- les obligations françaises / européennes ;
- les recommandations opérationnelles SER Guides.

## Public cible

- micro-entrepreneur ou société en France ;
- marchand Shopify souhaitant ouvrir un canal TikTok Shop ;
- marque DTC ou commerce local ;
- vendeur débutant qui n'a jamais utilisé Seller Center.

## UX cible

- diagnostic initial en 7 questions ;
- parcours conseillé selon 4 profils : produit non validé, produit validé sans audience, audience sans shop, shop déjà actif ;
- calculateur de marge TikTok Shop ;
- simulateur commission créateur / affiliation ;
- calculateur de seuil de rentabilité ;
- score « produit adapté à TikTok Shop » ;
- checklist onboarding ;
- checklist fiche produit ;
- checklist lancement 14 jours ;
- scripts créateurs / UGC à copier ;
- tableau KPI hebdomadaire ;
- recherche plein texte + progression locale.

## Principes de rigueur

- toute règle datée est accompagnée d'une date de revue ;
- les frais TikTok sont modifiables dans les calculateurs ;
- les politiques de produits interdits / restreints ne sont jamais résumées comme exhaustives ;
- les règles TVA / rétractation sont renvoyées aux sources officielles ;
- aucune donnée de performance n'est utilisée comme promesse individuelle.

## Direction artistique

Famille : **Commerce social éditorial**

Palette : noir profond / graphite / crème / accent rose-rouge TikTok sobre.

Typographies : Inter / system sans.

Univers : smartphone vertical, Seller Center, cartes KPI, étiquettes colis, contenus courts, live shopping, créateurs et dashboard.

## Deck Instagram

1. Hook : « TikTok Shop n'est pas juste TikTok + un bouton Acheter. »
2. Valeur : les 5 chiffres à calculer avant de lancer : prix, coût rendu, commission plateforme, commission créateur, marge après acquisition.
3. Produit : « TikTok Shop 2026 — de l'inscription aux premières ventes » + 4 outils interactifs + plan 14 jours.
