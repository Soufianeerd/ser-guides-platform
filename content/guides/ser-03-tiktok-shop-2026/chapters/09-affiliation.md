# 9 — Lancer l'affiliation créateurs

Le programme d'affiliation permet aux créateurs de promouvoir vos produits en échange d'une commission sur les ventes éligibles. [S09]

## Deux modes

### Collaboration ouverte
Vos produits peuvent être découverts par un ensemble large de créateurs. C'est utile pour observer qui s'intéresse naturellement à votre offre. [S03] [S10]

### Collaboration ciblée
Vous invitez des créateurs spécifiques pour promouvoir certains produits. [S10]

## Fixer la commission

Ne copiez pas un pourcentage trouvé sur une vidéo. Calculez d'abord votre marge.

Commission créateur maximale =
Marge avant créateur
− marge minimale que vous voulez conserver.

TikTok publie parfois des repères par catégorie dans ses contenus de formation, mais ce sont des conseils opérationnels, pas des taux obligatoires. [S11]

## Échantillons

Un échantillon gratuit est un coût d'acquisition. Suivez :
- coût produit ;
- coût expédition ;
- vidéos réellement publiées ;
- ventes attribuées ;
- GMV ;
- commission ;
- marge nette.

## Brief créateur

Donnez :
- cible ;
- problème ;
- bénéfice ;
- 3 preuves ;
- 3 interdits ;
- 3 angles ;
- CTA ;
- mentions réglementaires nécessaires.
