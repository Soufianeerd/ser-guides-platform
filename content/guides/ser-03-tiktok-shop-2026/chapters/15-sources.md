# 15 — Sources officielles et points à re-vérifier

Le fichier `SOURCE_PACK.md` contient les liens complets et la date de revue de chaque source.

## Avant chaque lancement

Revalidez :
1. commission plateforme de votre catégorie ;
2. éventuelle réduction nouveau vendeur ;
3. produits interdits / restreints ;
4. options d'expédition disponibles ;
5. politique retours ;
6. conditions affiliation ;
7. TVA de vos marchés ;
8. conditions vendeurs TikTok Shop applicables à votre compte.

## Sources prioritaires

- TikTok Shop Academy France / UE ;
- TikTok Newsroom pour le contexte produit ;
- DGCCRF / economie.gouv.fr ;
- Commission européenne / Your Europe pour TVA transfrontalière.
