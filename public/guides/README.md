# SER Guides — visual assets

Each guide uses a reusable 3-card editorial deck.

## Convention

`/guides/{slug}/{locale}/01-hook.jpg`
`/guides/{slug}/{locale}/02-sources.jpg`
`/guides/{slug}/{locale}/03-guide.jpg`

Locales: `fr`, `en`.

## Art direction

- Editorial/library aesthetic, premium but human.
- Real desk/book/workspace imagery rather than generic SaaS/AI graphics.
- Strong navy typography, white/ivory surfaces, one accent color per niche.
- Card 1: hook/problem.
- Card 2: useful proof/sources/checklist.
- Card 3: product reveal, benefits and CTA.
- Keep a common SER Guides composition system while changing the niche accent palette and scene props.
- The same three cards are used on Instagram and on the corresponding product page.
